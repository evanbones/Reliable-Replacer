### Configuration Location
The mod watches the `./config/reliable_replacer/` folder in your instance.
* You can create any number of `.json` files in this folder.
* The mod loads all JSON files found in this directory and its subdirectories.
* **Reloading**: You can reload changes in-game using `/reload`

### Global Configuration
Global settings are found in `config/reliable_replacer.json` or via the **Cloth Config** menu in-game.

### JSON Structure
A rule file can contain a single rule object or an array of rule objects.

**Single Rule:**
```json
{
  "inputs": ["minecraft:dirt"],
  "output": "minecraft:stone"
}
```

**Multiple Rules:**

```json
[
  {
    "inputs": ["minecraft:dirt"],
    "output": "minecraft:stone"
  },
  {
    "inputs": ["minecraft:gravel"],
    "output": "minecraft:sand"
  }
]

```
