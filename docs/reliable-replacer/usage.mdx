The mod watches a specific folder in your instance for JSON files: `./config/reliable_replacer/`.
You can place as many JSON files as you like in this folder or in subfolders.

If the folder is empty when the game starts, a `example_replacements.json` file will be generated automatically to help you
get started.

### Global Configuration

Global settings can be configured via the **Cloth Config** screen in-game or by editing `config/reliable_replacer.json`.

### JSON Structure

You can define a single rule or **multiple rules** in a single JSON file. To define multiple rules, simply wrap them in
a JSON Array `[...]`.
