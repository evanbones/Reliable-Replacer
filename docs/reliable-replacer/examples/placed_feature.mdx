---
title: Feature Replacements
hide_meta: true
---

Reliable Replacer allows you to target blocks specifically during the world generation phase, based on the **Placed Feature** that is creating them. Note that this will **not** work with retrogen!

This is highly powerful for modifying vegetation, ores, or other scattered features without affecting the rest of the world.

### Removing Features

You can completely prevent a feature from generating using `cancel_feature`. This prevents the game from placing any blocks for that specific feature instance.

This rule prevents Oak Trees (`minecraft:trees_plains`) from generating in the Plains biome.

```json
{
  "features": ["minecraft:trees_plains"],
  "cancel_feature": true
}

```

### Modifying Features

Instead of removing a feature, you can modify the blocks it places. This allows for unique variations of existing vanilla features.

**Example: Stone Trees**

This rule targets the Oak Tree feature and replaces all Oak Logs with Stone, but only while that tree is generating. Logs placed by players or other structures will remain normal.

```json
{
  "inputs": ["minecraft:oak_log"],
  "output": "minecraft:stone",
  "features": ["minecraft:trees_plains", "minecraft:trees_forest"]
}

```

### Filtering by Feature

You can also use features as a filter for broader changes.

**Example: Coal Ore -> Diamond Ore**

This rule replaces Coal Ore with Diamond Ore, but only if the coal was being generated by a specific ore feature.

```json
{
  "inputs": ["minecraft:coal_ore"],
  "output": "minecraft:diamond_ore",
  "features": ["minecraft:ore_coal", "minecraft:ore_coal_buried"]
}

```
